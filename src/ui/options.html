平台字幕

本地模型转录

优先快速提取音轨，再切片交给本机 ASR。YouTube、B 站可运行 npm run fast-asr； 普通视频可直接离线解码。仅在两者不可用时按播放速度录音。

润色

任何 OpenAI 兼容的 /chat/completions 端点都行——本机 Ollama、LM Studio、自建网关， 或你已付费的服务商。插件按「段落边界」分块并发发送，每块带上一块的尾句作为上下文， 并要求模型逐条按 id 返回，对不上就整块保留原文。
